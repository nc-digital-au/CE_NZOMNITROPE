Use Case:
A patient accesses the SurePal usage guides and Consumer Medicine Information from the Home dashboard.

Test:
Patient access resources - PDF guides

Preconditions/Instructions:

Preconditions:
- The patient is logged in to the OmniPal portal

Instructions:
1. From the Home dashboard, locate the Resources section.
2. Click on "SurePal 5mg How to use guide" link.
3. Return to the Home dashboard.
4. Click on "SurePal 10mg How to use guide" link.
5. Return to the Home dashboard.
6. Click on "SurePal 15mg How to use guide" link.
7. Return to the Home dashboard.
8. Click on "Consumer Medicine Information" link.

Pass Criteria:
- Each SurePal guide link opens the corresponding PDF document in a new tab/window.
- The Consumer Medicine Information link opens the Medsafe CMI PDF (https://www.medsafe.govt.nz/Consumers/CMI/o/omnitrope.pdf) in a new tab/window.
- All PDF documents are readable and display correct content.
